# SnapSmash · 찍고깨

설치 없이 사진을 찍고 터치해 깨뜨리는 모바일 브라우저 앱입니다.

## 실행

`index.html` 하나로 동작합니다. 별도 설치, 빌드, 외부 라이브러리와 서버가 필요 없습니다. 정적 HTTPS 호스팅에 업로드하고 스마트폰 브라우저에서 접속하세요.

GitHub Pages를 사용하려면 저장소 **Settings → Pages → Deploy from a branch → main / (root)** 를 선택하세요. 이 설정은 자동으로 활성화하지 않았습니다.

1. 샘플 화면을 터치해 바로 체험합니다.
2. **카메라로 촬영하기** 또는 앨범 버튼으로 사진을 선택합니다.
3. **유리 / 콘크리트** 모드를 선택하고 같은 부위를 여러 번 터치합니다. 첫 타격에는 금이 가며, 유리는 약 3회, 콘크리트는 약 4회부터 중심부 파편이 떨어집니다. 주변부는 더 여러 번 타격해야 합니다.
4. 남은 사진을 계속 두드리며 파괴 진행률과 연타 횟수를 확인합니다.
5. **다시 복원**으로 반복합니다. 상단 음표 버튼으로 소리를 끌 수 있습니다.

## 구현

- Canvas 2D 기반 2.5D 파편: 110개 보로노이 셀을 반평면 클리핑으로 생성하고 사진 텍스처를 입힙니다.
- 타격 지점 주변에만 손상이 누적되며, 임계값을 넘은 파편만 분리됩니다. 구멍을 다시 타격하면 남은 가장자리로 파괴가 확장됩니다.
- 깨진 면적 기준 파괴 진행률, 700ms 이내 연타 표시, 타격 지점의 충격파를 제공합니다.
- 터치 위치를 기준으로 방향과 속도를 계산하고 중력, 회전, 원근 크기 변화와 페이드 효과를 적용합니다.
- 유리와 콘크리트별 테두리, 질감과 타격음을 구분합니다.
- Web Audio로 타격음과 파열음을 합성합니다.
- 지원 기기에서 균열 타격은 짧은 진동, 파편이 떨어질 때는 강한 진동 패턴을 사용합니다.
- 터치 영역에서 기본 제스처를 막고, 안전 영역과 동적 뷰포트에 대응합니다.
- 사진은 최대 1600px로 줄여 메모리에서만 처리하며 업로드하거나 저장하지 않습니다.

## 브라우저 제약

- iPhone Safari는 Vibration API를 지원하지 않습니다. 화면 흔들림과 타격음은 사용할 수 있습니다.
- `capture="environment"`는 후면 카메라 사용을 요청하는 힌트입니다. 브라우저와 OS에 따라 카메라 선택 화면이 먼저 표시될 수 있습니다.
- 소리는 사용자 터치 후 재생됩니다. 브라우저/기기 설정에 따라 제한될 수 있습니다.
- JPEG/PNG 등 브라우저가 해독 가능한 이미지가 필요합니다. HEIC는 브라우저별로 지원이 다릅니다.
- 동작 줄이기 설정 시 화면 흔들림과 파편 기울이기를 줄입니다.
- 데스크톱에서는 모바일 폭의 체험 화면으로 표시됩니다.

## 검증

JavaScript 문법 검사 및 모의 Canvas 환경에서 두 재질의 첫 타격 시 균열만 발생하는지, 반복 타격 시 국소 파괴되는지, 남은 사진이 유지되는지, 계속 타격하면 전체 파괴에 도달하는지, 복원 시 상태가 초기화되는지 확인했습니다. 실제 모바일 카메라, 음향, 진동 및 시각적 브라우저 QA는 별도 실기기 확인이 필요합니다.
